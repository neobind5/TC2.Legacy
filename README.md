# TC2.Legacy
Fork of Korequest & TC2 Overhaul aiming to stay in line with what made TC1 fun.
Please contribute!! It's a lot of work! Playtesting is viable with current build.

## Goals:
- Gamemode Balancing (30%)
    - Occasional Playtests.
- Progression Rework (80%)
    - Earlygame (Done!)
    - Midgame (~30%)
    - Lategame (~5%)
- Simplifying Item Management (Done!)
- Building Rework (90%)
- Faction Rework (50%)
- Vehicle Rework (25%, On Hold)

See the PLANNER for more in-depth breakdowns of each goal.
